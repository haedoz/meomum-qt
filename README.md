# 말씀일지

성경을 읽고 QT, 기도, 생각, 구절 메모와 형광펜을 기록하는 개인용 웹앱이에요.

## 사용하기

1. 사이트를 열고 **설정 → 내 성경 자료 → 성경 번역본·자료 추가**를 눌러 사용할 성경 번역본 파일(.bdb)을 선택하세요. 주석(.cdb), 원전분해(.sdb), 원어사전(.dct) 파일은 필요할 때 추가하세요.
2. 가져온 파일과 개인 기록은 사용하는 기기의 브라우저에 저장돼요. 다른 기기로 기록을 옮길 때는 **설정 → 기록 백업**에서 내보내고 가져오세요. 가져오기는 그 기기의 기존 기록을 백업 내용으로 바꿔요.
3. 공개 저장소에는 앱 파일만 올려 주세요. 성경 자료와 개인 기록 백업 파일은 앱 안에서 각자 가져오면 돼요.

성경 화면에서 기본 번역본을 고른 뒤 **오늘**로 돌아가면 ‘오늘의 말씀’도 같은 번역본으로 표시돼요. 그 번역본에 같은 구절이 없으면 그 안에서 읽을 수 있는 구절을 골라요. 달력의 지난 말씀과 이미 작성한 묵상은 보존돼요.

## GitHub Pages에 올리기

1. 새 공개 저장소를 만들고 이 ZIP을 풀어 나온 파일과 폴더를 저장소 최상위에 올려요. `index.html`이 저장소를 열었을 때 바로 보여야 해요. 숨김 파일인 `.nojekyll`도 포함해 주세요.
2. 저장소의 **Settings → Pages**에서 **Source → Deploy from a branch**를 선택해요. **Branch**에서 **main**과 **/ (root)**를 고른 뒤 저장해요.
3. 배포가 끝나면 Pages 설정 화면에서 사이트 주소를 확인할 수 있어요.

기존 사이트를 업데이트할 때는 같은 저장소와 배포 경로에 ZIP 내용을 덮어쓰고, 배포가 끝나면 사이트를 새로고침하세요.

## 포함된 외부 구성 요소

- Pretendard 글꼴의 라이선스는 `fonts/Pretendard-OFL.txt`에서 확인할 수 있어요.
- sql.js의 라이선스는 `vendor/sql-js-LICENSE.txt`에서 확인할 수 있어요.
